## 根拠区分の内訳（考え方）
- 寄与（contribution）リンクは、その素材・試料自体を対象にした GC-O／AEDA／OAV／再構成／欠落試験／官能／DoT 等の原著がある場合に限る。2026-10-31 のスポット監査（33件抽出）で適正25／注記修正6／出典取り違え修正2を確認した（詳細は監査記録）。
- 素材プロファイルは全122件がアロマ＋感覚の複合署名で相異なる（2026-11-01 の統合監査で再検証。アロマ署名のみでは115種で、同一になる7グループはいずれも理由を分類済み）。プロファイル空は原著に基づく理由がある2件（唐辛子：品種別データ未確認／ドミニカ共和国産 Trinitario：試料内ばらつきが本質）のみ。
- カカオ遺伝集団は、香味の足がかりがある Nacional と Criollo の2集団だけを推測プロファイルつきで素材化し、残り8集団は用語辞典に分類情報として収録した（集団レベルの香味実測は存在しない）。

## 調査不足・未収録（優先順位つき）
1. 茶品種の個別実測プロファイルの拡充（金萱・紅玉の成分同定、ダージリンのクローン別香気特性等は未収録）。
2. 唐辛子の種別素材分割（種レベルの差を示す原著は確認済み。素材分割と品種別プロファイルは次期課題）。
3. 緑花椒（Zanthoxylum schinifolium）の素材化（原著4件は確認済み、未統合）。
4. 保留中の素材：ロングペッパー、グレインズ・オブ・パラダイス、チャービル（研究間の食い違い・寄与研究不足のため）。
5. 出典の本文精読の継続（クミン Ravi 2013 の全文確認が積み残し）と、台帳転記472件（うち bibliographic 43件）・書誌未同定メモ818件の再確認による格上げ。第3バッチで格上げしきれなかった残り（abstract 未到達の候補171件・未到達165件、docs/research/round11/ 参照）が対象。
6. シミュレーションの数値モデルは3件導入済み。残る候補（カカオ色変化等）は本文の表が前提であり、条件が満たされるまで導入しない（docs/SIMULATION_MODELS.md に不採用の記録）。
