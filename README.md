# 科学ペアリング研究ラボ（Flavor Pairing Lab）

お茶・スパイス・ハーブ・チョコレートを横断する、科学ペアリング探究Webアプリです。
ログイン不要・インストール不要で、URLを開くだけで使えます。

研究用アプリです。初心者向けのお茶×チョコレートアプリ（sylpica/pairing）とは独立したプロジェクトです。

## できること
- **ペアリング**: 2〜4素材を自由に組み合わせ、共通点・相違点・味覚の関係・知覚の相互作用を、根拠区分（実測／一般的知見／推測／情報不足）つきで探索。配合比率（質量比）の指定も可能
- **素材検索**: 分類 × 産地 × 品種・系統の三軸で絞り込み
- **香味化学**: 香り専用ホイール ⇄ 化合物 ⇄ 素材の双方向参照（検出と寄与を区別）
- **焙煎・抽出シミュレーション**: 温度・時間・素材量・湯量を操作し、文献に基づく定性的な傾向と限界を表示
- **文献・用語辞典**: 出典一覧（主張できる範囲つき）と用語解説、実データからの収録集計

## 科学データの方針
- 科学的事実を創作しません。根拠のない相性スコア・確率・精密な数値は作りません。
- 化合物の「検出」と「香味への寄与」を区別します。GC-MSで検出されただけの成分を寄与成分とは表示しません。
- ペアリングは化合物の足し算では判断しません。知覚レベルの相互作用として説明します。
- 論文の文章・図表は転載していません。方針の詳細は docs/EVIDENCE_POLICY.md、モデルは docs/SIMULATION_MODELS.md、監査記録は docs/MUSE_IMPLEMENTATION_AUDIT.md を参照してください。
