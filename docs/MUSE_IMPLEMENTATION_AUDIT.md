## 第4ラウンド：初心者用 pairing チャットの修正指示の横展開（2026-10-31）

- **ホイールの無地セグメント解消**（pairing 第6弾の指示「文字が小さくなってもいいからホイールに乗せて」）：本アプリのホイールはノート名を輪に描いていなかった（凡例のみ）ため、ノート名を段階縮小（9.5→6.5px）で必ず描くようにした。化合物名も同様に段階縮小（6.8→5.0px）してから初めて省略に回す。
- **味モード追加**（pairing の指示「味も追加。切替ボタンはホイールの少し上」）：素材詳細とペアリングに「香り／味わい」切替をホイール直上に新設し、味わいホイール（TasteWheel）を実装。設立仕様「ホイールは香り専用」は「香りと味を同一ホイールに混ぜない」分離原則として解釈し、切替式で両立させた（同一画面に混在させない）。組み合わせ表示の重ね合わせは「表示用であり混合物の実測ではない」旨を明記し、強さは最大値・根拠区分は同強度で弱い方を採用する保守的な合成にした。
- **3階層の明示**（pairing 第8弾の方向：大分類→中分類（具体名）→小分類（寄与化合物））：本アプリはノート名（中分類相当）と化合物の輪（小分類相当）を同時表示する設計のため、ドリルダウン化はせず、凡例を大分類（カテゴリ）見出しでグループ化し、ノート詳細の見出しを「カテゴリ：ノート名」に統一して階層を明示した。同時表示を維持する理由は、研究用では全体の見通しが優先されるため。
- **部分指定の一般化**（pairing の指示「分類のみ・2軸だけでもホイールが出る、全種類に適用」）：本アプリの素材検索は既に連動候補＋「指定しない」で同等を満たしていることをコードで確認した（対応済み）。

## 第12ラウンド：味わいホイールの3階層化（2026-11-01）

### ユーザー判断の経緯
- 初心者用 pairing アプリで全面改修された「味わいホイールの3階層化」（大分類＝味／中分類＝具体名／小分類＝化学物質）を lab にも適用することが、横展開ウォッチの (d) 項目としてユーザーに確認され、「labにも味の3階層化を適用する（根拠の範囲内で）」（2026-11-01 00:45）＋「根拠がなければ推測してください」（00:46）と確定した。
- 解釈：設立仕様の「味わいホイールは味覚・口腔感覚のみ（分離の原則）」は表示構造についてはこの判断が優先する。ただしデータ層の分離（感覚データと香味ノートの区別、実測と推測の区別）は維持する。根拠のない対応づけは推測（inferred）として区別表示すれば作ってよい。

### 対応づけデータ（src/data/taste-note-map.ts、新設）
- 方式：主対応1つ方式（1ノート→最大1つの味。第2階層の重みの二重計上を避け、第1階層の％計算を保つため）。各対応に根拠の種別つき説明文 (a) 呈味成分／(b) 味覚―嗅覚相互作用／(c) 推測 を保持する。sourceIds は再確認済みレジストリの ID のみ（台帳 ID は使わない）。
- 結果：42ノート中26件に対応づけ。一般的知見（general）17件＝(a) 呈味成分16件（柑橘・リンゴ洋ナシ→酸味／ドライフルーツ・蜂蜜・ミルキー・焦がし→甘味／海藻磯→うま味／ミント様・カンファー様→冷感／アニス様→甘味／シナモン・クローブ様→温感／生姜・胡椒様→辛味／コーヒー・カカオ→苦味）＋(b) 相互作用1件（バニラ→甘味増強。原著2件を出典に付与）。推測（inferred）9件（ベリー・核果・トロピカル・果実全般・キャラメル・クリーミー→甘味、カルダモン様→冷感、温かいスパイス→温感、焙煎全般→苦味）。アニス様（アネトール）とカカオ（Stark 2006）にのみ出典を付与し、それ以外の (a)(b) は「対応を直接支える出典がレジストリに無い」場合は付けない作法とした（化合物データ側の出典で代替しない）。
- 対応なし16件と理由：jasmine／rose／orchid／lavender／floral-general（花の香りに味への足がかりなし）、green-leaf（香気成分は呈味せず、葉物食品の味は食品ごとに異なる）、green-vegetable（品目ごとに味が異なる）、hay（足がかりなし）、herb-general（個別ハーブに依存）、toast（パンの甘味はデンプン分解由来で香りの対応としては任意）、smoky（燻製食品の味は加工条件に依存）、almond／hazelnut／nut-general（実の味は脂質のまろやかさが主で基本味対応が任意）、wood／earth（呈味の対応なし）。渋味（収斂感）に対応するノートは設けない（収斂の根拠はポリフェノール等の感覚データ側で扱う）。
- 判断した点：ベリー→甘味増強の相互作用研究（Frank 1988／1989 等）は台帳にのみ存在し再確認済みレジストリに無いため、(b) ではなく (c) 推測として扱った。キャラメル（甘い香りのノート）も直接の原著がレジストリに無いため推測とし、物質由来の「焦がし」（砂糖の加熱物）とは扱いを分けた。camphoraceous は代表化合物1,8-シネオール自体が冷感を持つため (a)、cardamom-note はシネオール含有からの一段の推論のため (c) とした。
