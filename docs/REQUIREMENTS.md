# 要件（統合指令書からの要約と実装対応）

本書は「Muse専用：科学ペアリング研究アプリ 完全統合開発指令書」の要件と、本実装の対応状況を対応づける。

## 対象
- リポジトリ: sylpica/flavor-pairing-lab（研究用）。初心者用 sylpica/pairing とは独立。
- 公開想定URL: https://sylpica.github.io/flavor-pairing-lab/

## 実装済み（第1弾）
- 4領域（お茶・チョコレート・スパイス・ハーブ）の素材検索。三軸（分類×産地×品種/系統/種）連動プルダウン：他軸と矛盾する候補は候補化されず、解除可能、一部未指定の検索が可能。
- ペアリング：2〜4素材、調和/対比/補完モード、配合比率（質量比・合計100%検証）、共通点・相違点・感覚の関係、共通化合物（注意文つき）、相互作用ルール（直接研究と一般機構を区別）。
- 香り専用ホイール（味覚は別グラフ）。ホイール→化合物→素材、化合物→香味→素材の双方向参照。
- 焙煎・抽出シミュレーション：スライダー＋数値入力同期、文献に基づく定性的傾向のみ、範囲外は警告し外挿しない、対象外素材は理由を表示。
- 根拠区分（実測/一般的知見/推測/情報不足）をデータと表示の両方で保持。相性スコア・根拠のない数値はなし。
- 文献・用語辞典画面。収録数は実データから集計し、網羅率は表示しない。
- 実装しない機能（個人記録・お気に入り・履歴・ログイン等）は実装していない。個人データの永続保存なし。

## データ方針
- お茶・チョコレート：初心者用 pairing で原著照合済みの書誌34件を再構成して活用。プロファイルは茶類・種類レベルの一般的知見が中心で、品種固有の実測とは区別する。
- スパイス・ハーブ：新規文献調査（査読論文・公的DB）に基づき構造化。精油組成と食品全体の組成を混同しない。
- ルビーは製品分類であり遺伝系統ではない（データ検証テストで担保）。

## 未完成・未検証（正直な残課題）
- 品種・系統レベルの拡充（茶品種の個別実測、カカオ遺伝集団・クローンの本格収録）は第1弾では限定的。
- 組み合わせ空間の全数検証は未実施（成立条件の独立検査＋境界値・代表例の検査に留まる）。「全数検証済み」とは報告しない。
- シミュレーションの数値モデル（抽出速度論等）は出典不足のため未採用。
- 実機（iPhone実端末）での最終確認は未実施。375px幅はレイアウト設計とエミュレーション前提。
- 詳細は docs/MUSE_IMPLEMENTATION_AUDIT.md と docs/DATA_COVERAGE.md を参照。
