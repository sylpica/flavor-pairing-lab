# pairing-inherited — 初心者用 pairing アプリの研究記録（継承資産）

このフォルダは、初心者用アプリ sylpica/pairing の `docs/research/` にあった研究記録27ファイルを、研究用アプリ flavor-pairing-lab の資産として継承したものです（2026-10-31、ユーザーの指示により取り込み）。

## 位置づけと格付けルール（重要）

- これらは pairing 側の文献調査ラインが蓄積した**研究記録**であり、記録形式は「書誌情報／主要な知見／適用範囲と限界／何に使えるか」で統一されています。
- ただし flavor-pairing-lab での**一次レコード再確認は未実施**のものが大半です。アプリの出典台帳（src/data/）へ転記する場合も、確認状態は `bibliographic`（書誌レベル・再確認待ち）とし、limits に「pairing の研究記録から転記。一次再確認は未実施」と明記します。
- **実測・寄与といった主張の根拠（素材×化合物リンク等）には、再確認済みの出典だけを使う**こと。再確認の過程で pairing 記録の誤りが実際に見つかっています（下記）。
- 未査読・Web 由来の記録（literature-expansion-e-web.md 等）は「参考情報」であり、実測の根拠にはしません。論文と食い違う場合は論文優先です。

## 再確認で判明した pairing 記録の誤り（このフォルダの記述を鵜呑みにしない根拠）

1. Huang 2022（祁門紅茶）：内容記述が PubMed 抄録と不一致（正：萎凋法3種の比較、リナロール rOAV 161／ゲラニオール rOAV 785 等）。
2. Wang 2022（大紅袍）：DOI/PMID の対応に誤り。
3. Flaig 2020：対象は西湖龍井ではなく径山茶。
4. Rottiers 2019：DOI の推測が誤り（正：10.1007/s00217-019-03364-3）。
