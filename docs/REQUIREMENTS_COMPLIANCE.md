## 章別の主な未充足（PARTIALの内訳と残課題）

- §3.3 未収録素材: アニス、オールスパイス、ジュニパーベリー（スパイス）、マジョラム、レモンバーベナ、パセリ（ハーブ）
- §3.4 多言語調査: 英語文献が中心。中国語・仏語等の系統的調査と J-STAGE の系統確認は未実施
- §5.1/5.4 データ構造: Cultivar／GeneticGroup／Clone は独立エンティティではなく素材の分離フィールドとして管理。データ状態（非検出・検出限界未満・矛盾する報告あり）の完全なモデル化は未実施（出典の確認状態と scopeNote で代替）
- §6.1 未収録の茶: 釜炒り茶、ダージリン／アッサム（産地別の紅茶。現状は「紅茶（一般）」）
- §6.2 茶品種: 具体名は やぶきた のみ。おくみどり、べにふうき、そうふう、さやまかおり、つゆひかり、青心烏龍、金萱、紅玉は未収録
- §6.3 カカオ: 遺伝集団（研究定義の10集団）・個別クローンは未収録。伝統的分類と製品分類は分離済み
- §7.4 組み合わせ空間: 全数検証は未実施。成立条件の独立検査＋境界値・代表例の検査に留まる（未実施を全数検証済みとは報告していない）
- §8.6 食べ合わせと混合の区別: 【2026-10-31 改善ラウンドで対応済み・配信待ち】パネル表記を「比率＝混合（ブレンド）時の質量比。食べ合わせには適用しません」に変更
- §9.2 条件プリセット: 【同・対応済み】抽出に条件プリセット（低温60℃・120秒／中温80℃・60秒／高温95℃・30秒）を追加。増減ボタンは数値入力の標準スピナーのみ
- §9.3 スライダー配置: 【同・対応済み】焙煎・抽出とも操作部（スライダー＋数値入力）を結果より前に配置へ変更
- §10.6 ホイールのキーボード操作: 凡例ボタン経由の選択は可能。SVGセグメント自体のフォーカス・キー操作は未対応
- §11.1 化合物メタ: CAS・化学式は一部のみ設定。PubChem CID は未収録。濃度はリンクの conditions テキストに含まれる場合のみ
- §11.2 未収録の重点化合物: グアイアコール、有機酸類、糖類
- §13.1 集計表示: 【2026-10-31 改善ラウンドで対応済み・配信待ち】統計カードに品種・系統（種類数）／産地（種類数）／香味ノート数／リンク根拠内訳（実測・一般・推測）を追加。出典一覧に題名・著者・誌名での絞り込み入力も追加
- §14.3 配置規則: 【同・部分的に対応】お茶×チョコ2素材時、素材別の表示（対比リスト）をチョコレート→お茶の順に並べ替え。画面全体の左右配置そのものは縦並びレイアウトのため未対応
- §14.4 写真・イラスト: 未使用。ライセンス確認が取れない画像を使わない判断による。イラストの自作も未実施
- §14.7 レスポンシブ: 375px は CSS 設計で対応。実機・実幅での操作検証は未実施。ダークモードは CSS 変数による部分的対応
- §16.2 食品安全性: safetyNote は一部素材（ナツメッグ、スターアニス、バジル、セージ、タラゴン等）のみ
- §17.3 原典照合: 要旨レベル確認が中心。本文精読は未実施
- §18 E2E: 8シナリオのうち実ブラウザでの完全実施は一部。操作系は実操作監査（6ジャーニー）で補完中
- §19.3 GitHub Actions: ワークフローなし（gh-pages ブランチへの直接配信方式を採用。Muse GitHub App に workflows 権限がないため）

## 結論

- FAIL（要件違反・虚偽）は 0件。Critical／High の未修正指摘は 0件。
- 完成条件24項目は PASS 18件・PARTIAL 6件。PARTIAL はいずれも「範囲の限定」であり、未解決を解決済みと表示している箇所はない。
- 残課題のうち UI 細部（§9.2 プリセット、§9.3 スライダー配置、§13.1 集計表示の拡充、§14.3 配置規則、§8.6 区別表示）は使いやすさ改善ラウンドで対応する。データ拡充系（品種・遺伝集団・未収録素材・化合物）は文献調査を伴うため次期課題とする。
